# Состояние проектов

Файл ведёт ПЯТНИЦА. Читается в начале каждого разбора, обновляется в конце.
Здесь — текущая картина, история в `log.md`.

## Кто босс
Работает в одиночку, делает проекты «под ключ»: видео, графика, веб-сцены,
брендинг. Ценит конкретику и результат, не любит воду.

## Проекты

### video/uniform — ролик iconmade «Униформа»
* Статус: собрана версия `iconmade_uniform_v13.mp4`, 1080×1920, 48.70 с.
* Стек: `scene.html` + `engine.js` (детерминированный `seek(T)`), покадровый
  рендер через Chromium (`render.py`), фон собирается в `build_bg.py`,
  музыка генерируется кодом (`music.py`), сведение — `mix.sh`.
* Документация: `BUILD.md` (сборка), `STORYBOARD.md` (раскадровка, безопасная
  зона Reels).
* Открытые вопросы: не заданы боссом.

### Веб-сцена на Three.js (вне этого репозитория)
* Есть описание системы восходящих частиц (`Points` + `ShaderMaterial`,
  аддитивный блендинг, весь расчёт в вершинном шейдере, за кадр пишется
  только `uTime`): две системы — «волновые» мошки над шторой и «светлячки»
  в сцене с деревом.
* Кода в репозитории нет — при первом разборе спросить у босса, где он лежит.
